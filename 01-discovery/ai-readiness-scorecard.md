# AI Readiness Scorecard

> "Readiness is not about technology. It's about people, process, and data—in that order."

## Purpose

This scorecard assesses an organization's readiness to successfully execute an AI pilot. It identifies gaps that must be addressed before pilot kickoff and predicts where challenges will emerge.

**Use this scorecard to:**
- Gate pilot approval (minimum score required)
- Identify remediation priorities
- Set realistic expectations
- Structure readiness workstreams

---

## Scoring Overview

### 10 Dimensions of AI Readiness

| # | Dimension | Weight | What It Measures |
|---|-----------|--------|------------------|
| 1 | Data Infrastructure | 15% | Quality, accessibility, and governance of data |
| 2 | Process Maturity | 12% | Standardization and documentation of target process |
| 3 | Technical Capability | 12% | Tools, platforms, and engineering capacity |
| 4 | Change Readiness | 12% | Organization's ability to adopt change |
| 5 | Leadership Alignment | 10% | Executive commitment and clarity |
| 6 | Domain Expertise Access | 10% | Availability of subject matter experts |
| 7 | Success Measurement | 8% | Ability to measure outcomes |
| 8 | Risk Tolerance | 8% | Appetite for experimentation |
| 9 | Resource Availability | 8% | People and budget commitment |
| 10 | Governance & Ethics | 5% | Policies for responsible AI |

### Scoring Scale

Each dimension scored 1-10:

| Score | Level | Description |
|-------|-------|-------------|
| 1-2 | **Critical Gap** | Fundamental capability missing |
| 3-4 | **Significant Gap** | Major work required before pilot |
| 5-6 | **Developing** | Gaps exist but addressable during pilot |
| 7-8 | **Capable** | Ready with minor improvements needed |
| 9-10 | **Advanced** | Strength to leverage |

## Dimension 1: Data Infrastructure (15%)

### Assessment Questions

| Question | Evidence to Look For |
|----------|---------------------|
| Is the required data digitized and accessible? | System access, query capability |
| Is there a single source of truth or are sources reconciled? | Data lineage documentation |
| How is data quality managed? | Quality metrics, cleanup processes |

| Score | Criteria |

| **5-6** | Primary data accessible with some effort. Quality variable. Some history available. |
| **7-8** | Data well-organized, accessible. Quality monitored. Sufficient history. Minor gaps. |

- ≤ 2 (Critical Gap) in dimensions 1-5 (Data, Process, Technical, Change, Leadership)

## Recommended Actions by Score Range

### For Scores 1-2 (Critical Gap)

| Dimension | Typical Actions |
|-----------|----------------|
| Data Infrastructure | Launch data foundation project. 3-6 month timeline before pilot. |
| Process Maturity | Process mapping and standardization initiative. |
| Technical Capability | Platform modernization or external partnership. |
| Change Readiness | Change management program with leadership commitment. |
| Leadership Alignment | Re-evaluate if this is the right initiative. Seek new sponsor. |
| Domain Expertise | Hire or contract expertise. Document knowledge. |
| Success Measurement | Define metrics and start baseline collection immediately. |
| Risk Tolerance | Set expectations with leadership. Start with very small pilot. |
| Resource Availability | Reallocate or delay pilot until resources available. |
| Governance & Ethics | Develop basic policies before any AI work. |

### For Scores 3-4 (Significant Gap)

| Dimension | Typical Actions |
|-----------|----------------|
| Data Infrastructure | Targeted data quality improvement. Access workstream. |
| Process Maturity | Document as-is process. Identify variance sources. |
| Technical Capability | Upskilling plan. Cloud migration if needed. |
| Change Readiness | Stakeholder engagement plan. Address specific concerns. |
| Leadership Alignment | Increase sponsor engagement. Clarify success criteria. |
| Domain Expertise | Formalize SME time commitment. Capture knowledge. |
| Success Measurement | Define metrics before pilot. Establish baseline. |
| Risk Tolerance | Communicate pilot nature. Set realistic expectations. |
| Resource Availability | Confirm commitments. Secure budget. |
| Governance & Ethics | Establish minimum viable policies for pilot. |

### For Scores 5-6 (Developing)

| Dimension | Typical Actions |
|-----------|----------------|
| Data Infrastructure | Monitor data quality. Have backup plans for gaps. |
| Process Maturity | Document during pilot. Accept some variance. |
| Technical Capability | Plan for learning curve. Consider external support. |
| Change Readiness | Proactive communication. Quick wins to build trust. |
| Leadership Alignment | Regular sponsor updates. Escalation path clear. |
| Domain Expertise | Protect SME time. Backup SMEs identified. |
| Success Measurement | Lock in metrics at pilot start. |
| Risk Tolerance | Clear kill criteria. Regular checkpoint reviews. |
| Resource Availability | Track utilization. Early warning if at risk. |
| Governance & Ethics | Ethics review before go-live. |
